This offline forecaster estimates five quantiles for each GTA VI trophy's earn rate. It combines robust trends across Exophase snapshots with shared growth estimates and trophy-specific saturation.

## Run it

With Node 22, place `main.ts` at the root of the competition kit and run from that directory.

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
